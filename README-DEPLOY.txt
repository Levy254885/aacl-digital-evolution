2. Turn on SSL (AutoSSL / Let's Encrypt). .htaccess forces https://www.aaclglobal.com.
3. Pages: /  and  /about/
4. Submit https://www.aaclglobal.com/sitemap.xml to Google Search Console and Bing Webmaster Tools.
